# MoodApp 本地心理支持知识库

本目录只存储经过审核的心理健康支持资料、危机处置规范和学校资源，
不存储用户聊天记录、用户画像或任何个人身份信息。

## 目录约定

- `documents/`：原始资料，只接收人工审核后的 Markdown、TXT 或 PDF 文件。
- `manifests/`：源文档元数据与审核记录。
- `chunks/`：经过确定性分块生成的 JSONL 知识块。
- `index/`：本地向量索引和关键词索引，不提交用户数据。

## 引用约束

每次检索结果必须包含 `document_id`、`chunk_id`、来源名称、版本、权威方、
原文片段和相似度分数。模型不得在检索结果之外虚构来源或引用。

## 内容治理

导入资料前必须完成来源、版本、授权、审核人和审核时间登记。危机处置资料
必须优先采用学校心理中心、国家/国际公共卫生机构或正式学术出版物来源。
