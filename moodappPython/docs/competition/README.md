# AIC 应用成效证据包

本目录用于收集比赛答辩可核验的应用成效证据。所有结果必须来自真实测试，禁止把目标值、演示数据或离线快照写成已达成结果。

## 三条证据链

1. **算法证据**：红队、安全、RAG、性能和故障注入报告。
2. **用户证据**：使用虚构场景完成任务后的匿名可用性数据。
3. **专家证据**：心理学教师或咨询师对脱敏合成案例的独立评分。

## 使用顺序

1. 使用 `user-usability-template.csv` 记录匿名任务测试。
2. 使用 `expert-review-template.csv` 记录专家独立评审。
3. 使用 `algorithm-comparison-template.csv` 记录同一测试集上的改进前后结果。
4. 汇总时保留样本量、测试日期、评测版本和原始报告路径。

## 数据边界

- 不收集姓名、学号、手机号、诊断信息或真实危机经历。
- 用户测试只使用预先准备的虚构场景。
- 参与者可以随时退出；出现不适立即停止。
- 系统用于心理支持和风险提示，不替代医学诊断或专业治疗。
- 未完成真实用户或专家验证的指标必须写“待采集”，不得用目标值替代。

当前已经通过代码验证的证据见 [TECHNICAL_EVIDENCE.md](TECHNICAL_EVIDENCE.md)。
